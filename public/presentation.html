05 — RECHNUNG

So werden die Kosten berechnet

Die Anwendung fragt erst die Route ab und rechnet anschließend mit den passenden Fahrzeugdaten.

ROUTE ANFRAGENJavaScript
const { routes } =
  await Route.computeRoutes({
    origin: start,
    destination: ziel,
    intermediates: stopps,
    travelMode: 'DRIVING',
    fields: ['distanceMeters', 'path']
  });

In Alltagssprache: „Google Maps, finde die Fahrt von hier nach dort — inklusive Zwischenstopps.“

KOSTEN BERECHNENJavaScript
const liter =
  kilometer * verbrauch / 100;

const gesamt =
  liter * preisProLiter + parkKosten;

const proPerson =
  Math.ceil(gesamt / personen);

Der Verbrauch wird auf die Strecke umgerechnet. Danach teilen wir die Kosten durch die Mitfahrenden.

✓ Die Codezeilen sind echt — die Erklärung bleibt bewusst einfach.

06 — GOOGLE MAPS

So nutzt die App Google Maps

Eine API ist ein klarer Übergabepunkt: Unsere App fragt einen spezialisierten Dienst an und verarbeitet dessen Antwort.

01
⌕

Ort finden

Eine Adresse oder Kartenposition geht an den Geocoding-Dienst. Zurück kommen Koordinaten und eine lesbare Adresse.

Adresse / Koordinaten→Adresse + Breite/Länge
02
↗

Route berechnen

Start, Ziel, Stopps und „Fahrt mit dem Auto“ gehen an Routes. Angefordert werden nur Distanz und Linienverlauf.

Wegpunkte + Fahrmodus→Meter + Routenpfad
03
✓

Ergebnis anzeigen

Die App zeichnet den Pfad auf der Karte. Die Treibstoff- und Parkkosten teilt sie anschließend selbst durch die Personenzahl.

Routenantwort→Linie + Kostenanteil
VEREINFACHTER AUFRUFJavaScript
const { routes } = await Route.computeRoutes({
  origin, destination, intermediates,
  travelMode: 'DRIVING',
  fields: ['distanceMeters', 'path']
});
// Distanz und Linienpunkte kommen zurück
🔑
Der Schlüssel ist kein Geheimnis im Browser

Der Maps-Schlüssel wird von der Webseite genutzt. Deshalb wird er in Google Cloud auf erlaubte Webseiten und APIs beschränkt. Er enthält keine Adressen — er ordnet die Nutzung dem eigenen Projekt zu.

Die Anfrage geht vom Browser an Google Maps. Die Kostenformel läuft danach im Browser; deine Fahrzeugdaten bleiben im lokalen Speicher deines Browsers.

07 — DATEN & EINGABEN

Was gespeichert und geprüft wird

↻

Preise nicht bei jedem Klick neu laden

Der Server hält abgerufene Treibstoffpreise eine Zeit lang im Zwischenspeicher. Wenn der Abruf fehlschlägt, steht ein Ersatzwert bereit.

✓

Eingaben werden geprüft

Zum Beispiel: Sitzplätze und Verbrauch müssen plausible Werte haben, bevor ein Auto gespeichert wird.

▣

Autos bleiben privat

Deine Fahrzeugdaten liegen im Browser-Speicher auf deinem Gerät, nicht in einer gemeinsamen Server-Datenbank.

◎

Die App bleibt leichtgewichtig

Das Frontend verwendet normales HTML, CSS und JavaScript, ohne großes UI-Framework.

Die Karte und Routenberechnung benötigen eine Internetverbindung und korrekt eingerichtete Google-Maps-APIs.
